# Official Sources

Consult these sources before changing version-sensitive behavior.

## WSL

- Advanced WSL settings, including wsl.conf and appendWindowsPath:
  https://learn.microsoft.com/en-us/windows/wsl/wsl-config
- Enable and verify systemd in WSL:
  https://learn.microsoft.com/en-us/windows/wsl/systemd

## Docker Engine

- Install Docker Engine from the official Ubuntu repository:
  https://docs.docker.com/engine/install/ubuntu/
- Configure the Docker daemon proxy:
  https://docs.docker.com/engine/daemon/proxy/
- Linux post-installation and non-root access:
  https://docs.docker.com/engine/install/linux-postinstall/

## GitHub

- Use GitHub SSH over the HTTPS port:
  https://docs.github.com/en/authentication/troubleshooting-ssh/using-ssh-over-the-https-port
- Published GitHub SSH key fingerprints:
  https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/githubs-ssh-key-fingerprints
- GitHub CLI authentication manual:
  https://cli.github.com/manual/gh_auth_login

## Python and uv

- Install uv:
  https://docs.astral.sh/uv/getting-started/installation/
- Install and manage Python with uv:
  https://docs.astral.sh/uv/guides/install-python/
- Manage Python tools with uv:
  https://docs.astral.sh/uv/concepts/tools/

## Node and Corepack

- Corepack documentation for the installed Node release:
  https://nodejs.org/api/corepack.html
- pnpm installation guidance:
  https://pnpm.io/installation

## OpenAI Codex

- Codex documentation:
  https://developers.openai.com/codex/

Re-check release support, command flags, fingerprints, and repository instructions when the local tool version differs from the environment described in references/lessons.md.
